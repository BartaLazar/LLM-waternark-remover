Field guide

Page
Paste or type your text here, then press Strike. Edit it and strike again to re-run with the current settings.
Every
Replace the first word, then every N-th word after it.
Senses
How many candidate meanings of a word to consider before ranking — applied to every checked source.
Threshold
How far a candidate's sense is allowed to drift from the word's dominant sense before it's rejected.
Slide
If a word has no usable synonym, try the next word instead of leaving that slot unfilled.
Multi‑word
Allow multi-word synonyms, like “give up” for “abandon”.
Sources
Which dictionaries to pull synonyms from. Check more than one to pool their candidates together — see the API docs for what Senses/Threshold mean for each one.
Ribbon
Black shows the plain result. Blk+Red marks each change inline, the original struck through next to its replacement. Dupl. shows the original and the result side by side, with a mark in the gutter next to every changed line.
Strike
Runs the rewrite with the current settings.
Corrections cards
One per change. Hover or click a card to find its word in the page; the chips swap in an alternative synonym; Reset puts the original word back — every view updates immediately.
Replaced words in the page
In Blk+Red or Dupl., click a red word to jump back to its card.
Copy / Download
Grab the current result text, including any Reset or alternative edits you've made.
